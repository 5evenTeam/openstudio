Bridge OpenCode to Roblox Studio.

OpenStudio is a local MCP bridge that lets AI agents inspect, edit, and build inside a live Roblox Studio session — scripts, UI, instances, logs, screenshots, tests, and more.

Built for Roblox production workflows

Everything stays local on 127.0.0.1 and works through the normal Roblox Studio plugin flow.

Realtime

Long-poll bridge

Near-instant command delivery with an HTTP bridge and a Roblox plugin poll loop.

Safety

Permissions & backups

Three permission levels, confirmation gates for destructive ops, and automatic script backups.

UI

StudioUI builder

Create complete Roblox UI trees from declarative node definitions, plus presets for panels, buttons, toggles, and lists.

Inspection

Instance tools

Read/write scripts, inspect instance trees, search, inspect, create, rename, and delete instances.

Testing

Game-wide tests

Compile scripts and scan UI for common issues like zero-size elements and empty labels.

Capture

Screen capture

Capture the Roblox Studio window as PNG and receive it inline in the MCP conversation.

Install in minutes

Requires Node.js 20+, OpenCode, and Roblox Studio.

1. Clone & build

Clone the repository, run npm install, then npm run build.

2. Configure OpenCode

Point your OpenCode MCP config at C:\OpenStudio\scripts\OpenStudio.bat (Windows launcher).

3. Install the plugin

Paste studio/OpenStudioPlugin.luau into Roblox Studio as a plugin and click Connect.

{ "mcp": { "openstudio": { "type": "local", "command": "C:\\\\OpenStudio\\\\scripts\\\\OpenStudio.bat", "args": [] } } }
